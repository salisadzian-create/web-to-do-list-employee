# web-to-do-list-employee
A lightweight and responsive Task Management Web Application designed for employees to organize their daily work agendas efficiently. Built using pure HTML, CSS, and Vanilla JavaScript with local persistence.

## ✨ Key Features
- **Task Management**: Easily add, complete, and delete tasks.
- **Priority Levels**: Set task priority (Low, Medium, High) with color-coded badges.
- **Due Date & Overdue Tracking**: Track task deadlines with automatic "LATE" status indicators for overdue tasks.
- **Customizable Profile**: Edit employee name and role dynamically (persisted per device).
- **LocalStorage Integration**: Keep all tasks and profile data saved in the browser so nothing gets lost on refresh.
- **Clean UI**: Modern header with real-time localized date display and separated "To Do" vs "Done" lists.

## 🛠️ Tech Stack
- **HTML5** - Semantic structure
- **CSS3** - Custom styling & responsive layout
- **JavaScript (ES6+)** - Dynamic DOM manipulation & LocalStorage logic
- **FontAwesome** - Icons
